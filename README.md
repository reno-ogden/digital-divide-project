/========================================================/
CONNECTED IS NOT THE SAME AS INCLUDED MULTIMODAL PROJECT
/========================================================/

This website is my final multimodal argument for ENGL 120. It focuses on the digital divide and explains why giving someone internet access does not automatically mean they are digitally included.

The website is mainly written for colleges, libraries, nonprofits, and community organizations that create or fund digital-access programs. My argument is that these programs should provide more than an internet connection.

Meaningful digital inclusion also requires:

Reliable internet
An appropriate device
Practical digital skills
Accessible websites and services
Continued human support

Programs should measure whether people can successfully participate and complete important tasks, not only how many people they connect.

/===================/
OPENING THE PROJECT
/===================/

Open the project folder in Visual Studio Code:

cd PATH/TO/connected-not-included
code .

If that command does not work, open Visual Studio Code and select File > Open Folder.

/======================/
PREVIEWING THE WEBSITE
/======================/

If you have the Live Server extension, right-click index.html and select Open with Live Server.

You can also run:

py -m http.server 8000

Then open:

http://localhost:8000

Press Ctrl+C to stop the server.

/=================/
AUDIENCE REVISION
/=================/

The first prototype was written for a general audience. Based on instructor feedback, I revised the final version to focus on the organizations and program leaders who make decisions about digital inclusion programs.

The website can still be understood by a general public audience, but its examples, interactive sections, and action plan now encourage program leaders to think beyond basic internet access.
