# Connected Is Not the Same as Included

This is an early prototype for my ENGL 120 multimodal argument about digital inclusion. It is intentionally simple so peer feedback can guide the final version.

## Prototype Features

- Draft thesis and page layout
- Interactive comparison
- Expandable framework cards
- One research statistic
- Scenario placeholder
- Draft takeaway and sources

## Planned Improvements

- Stronger visual design
- More research and source citations
- Completed interactive scenario
- Clearer calls to action
- Better accessibility and mobile support

## Open the Website

Open the project in Visual Studio Code:

```bash
cd PATH/TO/connected-not-included
code .
```

To preview it, right-click `index.html` and select **Open with Live Server**.

You can also run:

```bash
py -m http.server 8000
```

Then visit `http://localhost:8000`.
